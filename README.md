# Prosa.dev

Blog simples construído com Node.js, Express.js e EJS. A aplicação permite criar, visualizar, editar e excluir posts.

## Instalação

```bash
npm install
```

## Execução

```bash
npm start
```

Depois, acesse `http://localhost:3000`.

## Funcionalidades

- Criação de posts com título e conteúdo
- Listagem e visualização individual de posts
- Edição e exclusão com confirmação
- Mensagens de sucesso após as operações
- Data de publicação e atualização
- Página Sobre e página de erro amigável

Os posts são armazenados em memória e são perdidos quando o servidor é reiniciado.
